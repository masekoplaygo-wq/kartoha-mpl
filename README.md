# KARTOHA MPL

Прыгалка про картошку прямо в браузере.

**Играть:** https://masekoplaygo-wq.github.io/kartoha-mpl/

## Как играть

- Тапни **ИГРАТЬ** после загрузки.
- Держи палец на экране — картошка идёт к пальцу. Отпустил — останавливается.
- Прыгает сама: платформы обычные, движущиеся (синие) и ломкие (коричневые — выдерживают один прыжок).
- Каждая 10-я платформа с шансом 84 % даёт монету **+100**.
- 15 скинов: 1 стартовый, 12 из коробок, 2 за достижения (500 м и 1000 м).
- Коробки: `box` 100, `box rig` 500, `box oxide` 1000. Дубликат возвращает половину цены.
- Прогресс (монеты, скины, рекорд) хранится в браузере — в localStorage.

## Телефон

Сайт можно добавить на главный экран: в Chrome меню → «Добавить на главный экран».
Откроется без адресной строки, как приложение.

## Android APK

В этом же репозитории нет APK — он лежит на телефоне в `Downloads/kartoha mpl.apk`.

## Обновление сайта

```sh
cd kartoha
node tools/icon.js ../kartoha-site web
cp assets/index.html ../kartoha-site/index.html
cd ../kartoha-site
git add -A && git commit -m "update" && git push
```

GitHub Pages пересоберёт сайт за минуту.
